# Zhiyuan Daniel Yang — Personal Site

A responsive personal website built with plain HTML, CSS, and a small script: a project
gallery, a résumé-style list of experience, and a scroll-linked bouldering route.

- `index.html`: all content.
- `styles.css`: layout and colours, with a dark theme that follows the system setting.
- `script.js`: the CareMatch screenshot switcher and the climbing robot.
- `assets/`: project screenshots and figures (WebP), plus the link-preview image `og.jpg`.

## GitHub Pages

This repository is published automatically from the `main` branch at
`https://ddaniel-code.github.io/`.

## Local preview

Open `index.html` directly, or serve this folder with any static HTTP server.
